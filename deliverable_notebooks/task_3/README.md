# Task 3 — Hamiltonian Learning from Quantum Trajectories

## Overview

This task implements a **Neural Differential Equation (NDE)** approach to learning the parameters of a quantum Hamiltonian from time-series measurement data. Given a sequence of bitstring measurement outcomes at multiple time points, the model learns the Hamiltonian (and optionally noise parameters) that best explains the observed quantum dynamics.

Two dynamics models are supported:
- **Schrödinger** (noiseless): pure-state evolution.
- **Lindblad** (noisy): open-system evolution with dephasing and damping noise.

The learning model is a hybrid architecture combining explicit Hamiltonian parameters `θ` with a neural network correction term that captures higher-order or unknown physics.

## Workflow

### Step 1 — Generate synthetic data

Run `notebooks/generate_data.py` to produce a synthetic dataset. This script:
1. Reads `config/data_generation_configuration.yaml`.
2. Builds the Hamiltonian operators from the true parameters.
3. Prepares the initial quantum state.
4. Integrates the dynamics (Schrödinger or Lindblad) via RK4.
5. Samples bitstrings at each time step.
6. Saves `counts.csv`, `metadata.npz`, and `config_df.csv` to `data/`.

```bash
python notebooks/generate_data.py
```

### Step 2 — Train the model

Open and run `notebooks/trajectory_learning.ipynb`. The notebook:
1. Reads `config/lindbladian_learning_configuration.yaml` and the generated data.
2. Initializes Hamiltonian parameters `θ` and the MLP correction network.
3. Runs a **3-phase curriculum**:
   - **Phase 1**: Train both `θ` and the NN jointly.
   - **Phase 2**: Distil — freeze the NN and refine `θ` only.
   - **Phase 3**: Fine-tune the NN with `θ` fixed.
4. Plots learned vs. true Hamiltonian parameters, observables, fidelity, and loss curves.

## Configuration Files

### `config/data_generation_configuration.yaml`

Controls the synthetic dataset generated by `generate_data.py`.

| Parameter | Description |
|-----------|-------------|
| `L` | **Number of qubits.** Must match list lengths elsewhere. |
| `t_max` | Total evolution time. |
| `dt` | Integration time step. |
| `N_time_shots` | Number of time points to sample at. |
| `N_shots_per_time` | Number of bitstring measurements per time point. |
| `initial_state_kind` | Initial state: `"all_plus"`. |
| `hamiltonian_type` | **`"uniform_xyz"`** (6 global params) or **`"general_local_zz"`** (site-local params). |
| `dynamics_type` | **`"schrodinger"`** (pure state) or **`"lindblad"`** (open system). |
| `noise_model` | **`"global"`** (one T1/T2 for all qubits) or **`"local"`** (per-qubit T1/T2). |
| `T1_global` / `T2_global` | Global relaxation / dephasing times (used when `noise_model = "global"`). |
| `T1_list` / `T2_list` | Per-qubit relaxation / dephasing times (length `L`, used when `noise_model = "local"`). |
| `Jx_true`, `Jy_true`, `Jz_true`, `hx_true`, `hy_true`, `hz_true` | True coupling and field strengths for `"uniform_xyz"`. |
| `hx_list_true`, `hz_list_true`, `Jzz_list_true` | Site-local true parameters for `"general_local_zz"` (lengths `L`, `L`, `L-1`). |
| `seed_data` | Random seed for reproducibility. |

### `config/lindbladian_learning_configuration.yaml`

Controls the training run in `trajectory_learning.ipynb`.

| Parameter | Description |
|-----------|-------------|
| `L` | **Number of qubits** (must match the dataset). |
| `hamiltonian_type` | Hamiltonian model to learn: `"uniform_xyz"` or `"general_local_zz"`. |
| `use_noisy_dynamics` | `True` to use Lindblad dynamics during training; `False` for Schrödinger. |
| `learn_noise_params` | Whether to optimize noise rates during training. |
| `noise_model` | `"global"` or `"local"`. |
| `gamma_dephasing_init` / `gamma_damping_init` | Initial guesses for noise rates. |
| `N_epochs` | **Total training epochs** (distributed across the 3 phases). |
| `learning_rate` | Adam optimizer learning rate. |
| `dt` | Integration time step used during training (should match data generation). |
| `MODEL_TYPE` | **`"white"`**: learns explicit `θ` + NN correction. `"black"`: pure NN, no `θ`. |
| `NN_hidden_sizes` | **Hidden layer sizes of the MLP**, e.g. `[64]` for one hidden layer of 64 units. |
| `learn_theta` | Whether to optimize Hamiltonian parameters `θ`. |
| `Jx_init`, ..., `hz_init` | Initial guesses for `"uniform_xyz"` parameters. |
| `hx_list_init`, `hz_list_init`, `Jzz_list_init` | Initial guesses for `"general_local_zz"` (lengths must match `L`). |
| `PHASE1_SPLIT` / `PHASE2_SPLIT` / `PHASE3_SPLIT` | **Fraction of epochs** allocated to each training phase (must sum to 1). |
| `lambda_reg` | **L2 regularisation** weight on the NN parameters. Increase to penalise large corrections. |
| `noise_reg` | Regularisation weight on noise rates. Keep very small (e.g. `0.0001`). |
| `T_extrapolate_factor` | Factor by which to extrapolate time beyond `t_max` for validation. |
| `seed_init` | Random seed for weight initialisation. |
